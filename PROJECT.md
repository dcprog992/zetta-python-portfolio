# Как создавался Zetta Python

## Задача

Собрать курс Python, в котором можно сразу потренироваться после урока и вернуться к своей работе позже. Проект объединил учебный контент, практику в браузере и личный кабинет.

## Что сделано

| Часть проекта | Решение |
| --- | --- |
| Уроки | Четыре открытых урока для знакомства с курсом. Доступ к остальным управляется через аккаунт. |
| Практика | Сервер проверяет решение по правилам задания. В SQLite сохраняются последняя отправка и состояние урока. |
| Прогресс | Успешная проверка отмечает задание выполненным. Завершение курса рассчитывается по числу пройденных уроков. |
| Сертификат | При активном доступе и достаточном прогрессе открывается именная страница с номером. ФИО берётся из профиля. |
| Интерфейс | Навигацию по урокам адаптировали для телефона, вынеся список уроков в раскрывающееся меню. |
| Развёртывание | Приложение разворачивалось через Gunicorn под управлением systemd. История изменений хранится в GitHub. |

## Пример отладки

После обновления интерфейса страница урока возвращала HTTP 500. Шаблон обращался к `progress`, а маршрут не передавал это значение. В текущем коде сводка прогресса вычисляется на сервере и передаётся в шаблон. Тот же расчёт используется при проверке права на сертификат.

## Что показать в демо

Откройте бесплатный урок, отправьте решение под тестовым аккаунтом и перезагрузите страницу. Так можно показать проверку задания и восстановление введённого кода. В тестовом аккаунте с активным доступом можно дополнительно показать экран прогресса и выдачу сертификата.
