# Zetta Python

Веб-платформа для изучения Python. Ученик читает урок, пишет код в редакторе и получает результат проверки. Прогресс и последняя попытка сохраняются в аккаунте.

**Демо:** [zettapy.ru](https://zettapy.ru/)

## Возможности

- Четыре открытых урока и полный курс по активированному аккаунту.
- Проверка практических заданий и сохранение последней версии кода.
- Профиль с прогрессом и именной страницей сертификата после выполнения условий курса.
- Панель администратора для управления уроками и доступом пользователей.
- Адаптивная навигация по урокам.

## Стек

Python, Flask, Jinja, SQLite, HTML и CSS. Для запуска на сервере использовались Gunicorn и systemd.
